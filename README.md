# Choir Practice

Practice tracks for the Northland Community Choir's Fall 2026 program, *Footprints in Time*.

Singers open the site, pick their part once, and play their practice track or the full choir recording, with sections, repeat and starting notes. Tracks stream from the program's shared Google Drive folder.

- `index.html` is the whole page.
- `program.json` lists the pieces, each part's Drive files and the section times. It is generated from the Drive folder and Part Switcher.
- `config.js` holds the Google API key, restricted to the Drive API and this site's address.
